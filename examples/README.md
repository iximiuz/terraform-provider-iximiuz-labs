# Examples

This directory contains example Terraform configurations for the `iximiuz-labs`
provider. They serve as both documentation sources and runnable examples.

The `terraform-plugin-docs` generation tool uses the following conventions:

* **provider/provider.tf** — example for the provider index page
* **data-sources/`<full data source name>`/data-source.tf** — example per data source
* **resources/`<full resource name>`/resource.tf** — example per resource
